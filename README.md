# argos

once / soak 框架库 + dash。

| | |
|---|---|
| Git | `https://github.com/lpythu/argos` |
| PyPI | `argospy`（`argos` 已被占用） |
| import | `argos`（`src/argos/`） |
| CLI | `argos` |
| Dash | `https://argos.saidc.ai` |

写 case 去 [argos-pack](https://acahti.saidc.ai/saidc/argos-pack)。本仓不装 pack。

```bash
pip install argospy
```

CLI 零第三方依赖。`argos-pack` 只依赖 PyPI 上的 `argospy`。
